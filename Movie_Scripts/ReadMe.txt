The scripts of war movies had their title unchanged.
The scripts of Band of Brothers and The Pacific, where 2 scripts were merged into one, have the prefix "S_".
--> for example "BoB S_Holland"

The scripts of the other genres have their genre as a prefix in brackets.
--> for example "[DR]Titanic"

Genre Prefixes:
[AC]	= Action
[CO]	= Comedy
[DR]	= Drama
[FA]	= Fantasy
[PS]	= Psychological


The Tabledocument "Overview of Corpus.ods" contains all the sources of the scripts and general overview information.
The file was made with OpenOffice not with MS Excel. Import errors are possible.
